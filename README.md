# Plataforma CESAE Viagens ✈️

Projeto desenvolvido no módulo de Desenvolvimento Web, com a finalidade de estruturar a interface digital de uma agência turística recorrendo integralmente à biblioteca Bootstrap 5.3, sem recorrer a estilização CSS personalizada.

## 📄 Apresentação do Projeto

O portal CESAE Viagens constitui uma solução demonstrativa para o setor do turismo. O trabalho focou-se na implementação de componentes nativos do Bootstrap e na garantia de total responsividade em múltiplos dispositivos.

## 💻 Ferramentas Aplicadas

* HTML5
* Framework Bootstrap 5.3
